# sources/ — the inbox

Drop raw material here, one file per source. This is the "junk" the LLM distills from.

**What goes here:**
- Saved web pages, articles, threads (paste the text or a link + a few notes).
- PDFs, or text extracted from them.
- Meeting notes, Slack snippets, your own rough thoughts.

**You don't organize this.** It's a pile. The LLM reads the pile and writes the distilled
`README.md` one level up. Keep filenames descriptive (`author-topic.md`) so citations are easy.

> Tip: ask your AI to *"fetch this URL, save the relevant text as a new file in `sources/`,
> then update the topic's README.md and note what changed."*
