# MarkItDown

A free Microsoft command-line tool that converts PDFs, Word docs, and other formats to markdown
(`markitdown file.pdf > raw/papers/name.md`). It's how non-web sources enter the `raw/` layer of
the [[three-layer-architecture]], complementing the [[obsidian-web-clipper]] for web pages.
