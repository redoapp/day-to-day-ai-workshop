# Obsidian Web Clipper

A free browser extension (Chrome/Firefox/Safari/Edge) that turns a web page into a formatted
markdown note with one click, saved straight into `raw/articles/`. It's the quickest way to feed
the **Ingest** step of [[ingest-query-lint]]; for PDFs and docs, [[markitdown]] plays the same
role. [[hoeem-2026-llm-knowledge-base-course]]
