# Dataview

An [[obsidian]] plugin that turns the vault into a queryable database. It reads the YAML
frontmatter every page in this wiki carries (`type`, `tags`, `date_modified`, `source_count`)
and renders **live tables** — recently updated pages, concepts by source count, unprocessed
sources. It powers the [[dashboard]] note. [[hoeem-2026-llm-knowledge-base-course]]
